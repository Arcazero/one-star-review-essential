One original deadpan one-star review of an everyday essential — sleep — an entry for make.fun's "One-Star Review of Something Essential" bounty ($5 in USDC).

## The review

> Eight hours a night, every night, and I still wake up tired. Sleep is the only subscription that never delivers.

112 characters, one line. The full line also lives in `review.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
